# Tài liệu thiết kế lịch sử

Các tài liệu trong thư mục này lưu baseline và quá trình thiết kế trước bản PRD/SAD 2.0. Chúng không phải contract hiện hành; số lượng ảnh, cơ chế token và trạng thái triển khai được ghi theo thời điểm cũ.

| Tài liệu | Vai trò |
| --- | --- |
| [MASTER_SPEC](MASTER_SPEC.md) | Đặc tả và lịch sử các phase ban đầu |
| [REQUIREMENTS](REQUIREMENTS.md) | Yêu cầu/measurement plan gốc, ID cũ |
| [SYSTEM_ARCHITECTURE](SYSTEM_ARCHITECTURE.md) | Thiết kế hệ thống qua các phase trước |
| [PRD baseline](PRD_BASELINE_20261103.md) | Bản PRD trước lần biên soạn 2.0 |
| [SAD baseline](SAD_BASELINE_20261103.md) | Bản SAD trước lần biên soạn 2.0 |

Dùng [PRD hiện hành](../PRD.md), [SAD hiện hành](../SAD.md), [API](../API_SPECIFICATION.md), [database](../DATABASE_DESIGN.md) và source cùng release khi phát triển. Các liên kết bên trong tài liệu lịch sử có thể trỏ tới layout cũ; bằng chứng gốc trong `docs/verification/` và báo cáo nghiệm thu được giữ nguyên.
