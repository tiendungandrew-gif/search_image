## C. Kiến trúc Agent

Explicit Agent API → lightweight finite router → deterministic hoặc bounded JSON LLM planner → validate toàn DAG → execute → aggregate/revalidate → optional RagService → final response. Fast API vẫn gọi SearchService độc lập. Explicit text/metadata/explain/multimodal được ưu tiên trước auto-detection; chế độ thực trả trong response. [Kiến trúc/sơ đồ](AGENT_ARCHITECTURE.md).

LLM planner hiện chỉ diễn đạt template đã nhận diện, guard kiểm tra anchor/relationships/dependencies/filters. Không là general natural-language planner. Structured output sai bị reject, không thực thi code từ model. Không dùng internal model knowledge làm facts.

## D. Tool Registry

9 tools: semantic_image_search, multimodal_image_search, metadata_search, entity_lookup, relationship_lookup, get_related_entities, retrieve_image_details, rerank_images, rag_explain. Input/output JSON Schema, read permission, caps/timeouts và capability được công bố qua status. Search/rerank/RAG đều là adapters sang code hiện có. Không shell/SQL tùy ý/URL fetch/mutation/import tool. [Contract](AGENT_TOOL_DESIGN.md).

## E. Thực thi nhiều bước

Fixture chain anchor lookup → located_in city → inverse located_in landmarks → image search với verified association gate.4 tool calls, 3 logical hops. Safe references dùng step_id và entity_ids/image_ids có kiểu; từng input được kiểm tra lấy từ output trước. Tập UUID ảnh mong đợi được lấy từ upload receipt trước request. Actual result trùng receipt, không broad direct-search fallback.

Fixture deterministic completed 160.90ms; Gemini JSON plan + cùng chain completed 2221.68ms. Missing relation và conflict đều insufficient_evidence. [Sequence và semantics](MULTI_HOP_SEARCH.md), [raw fixture](verification/phase09/fixture_v3/fixture.json).

## G. State và phục hồi

Mỗi request có IDs, plan, typed outputs, traces, warnings/errors, deadline monotonic và budget riêng. planned → running → completed/partial/insufficient_evidence/timeout/failed/cancelled, terminal không chạy lại.3 hops,6 calls,1 replan,15s deadline,2s tools,4s planning attempt,2 concurrent Agent requests. Request chỉ giảm limits server. Không durable checkpoint hoặc personal memory.

Lặp tool fingerprint/cyclic DAG/traversal/no-progress bị chặn. Dependency thất bại không được tạo ID giả. Optional generation lỗi giữ ảnh đã revalidate, status partial. Cancellation nhả admission; SSE disconnect hủy child task. Trace không chứa private reasoning/query raw/API credentials. [State](AGENT_STATE_MANAGEMENT.md).

## H. Evidence aggregation

Dedup theo stable image/entity/evidence IDs; giữ thứ tự retrieval hoặc rerank đã chạy; lưu source step/tool. Image IDs được đọc lại qua EvidenceRetriever đối chiếu PG/Qdrant/MinIO; entities/relations/associations đối chiếu PG. Relational images bắt buộc link verified tới target entities. Stale/fabricated IDs bị loại; citations chỉ thuộc final images.

`relationship_summary` chỉ từ cạnh có nguồn; score cosine không chứng minh quan hệ. Thiếu evidence không là phủ định thế giới thực. `query_success` là execution structure, không phải chất lượng thông tin.

## I. RAG integration

Reuse provider/context/citation validator Phase 08. Agent có thể trả images khi generation disabled/unavailable. Native Gemini thật đã chạy trong integration/browser và benchmark; latest A4 generated **4/4**. Citation identity checks không thay người đánh giá semantic faithfulness. RAG chỉ giải thích caption/metadata thực có, không xác nhận địa lý bằng model memory.

Một lượt browser RAG cũ trả abstention hợp lệ; failure được giữ nguyên và test UI đã chuyển từ đòi câu chữ cố định sang validate structured outcome/citations/giữ ảnh. Không đổi prompt để che lỗi hoặc tự điền quality labels.

## J. API và frontend

Execution trả status/query_success riêng; HTTP200 không đủ kết luận thành công. API Agent có response root riêng; cập nhật contract so với phần reserved Prompt 02. [AGENT_API](AGENT_API.md).

SSE parser xử lý chunk UTF-8/CRLF, bounded output; tokens chưa validate không render. UI Agent hiện text input; stored-image multimodal hỗ trợ qua API. Desktop/mobile browser kiểm tra actual Agent images và missing knowledge; empty UI dùng mocked SSE được ghi rõ.

## N. Vấn đề và giới hạn còn mở

- [ ] Nhập bộ tri thức thật có nguồn được duyệt và image associations được xác nhận; hiện KB0/0/0.
- [ ] Human labels cho relevance/entity/relation/task correctness và faithfulness; Phase 08 review vẫn chờ, không tự chấm.
- [ ] Đánh giá Recall@10/MRR/nDCG và multi-hop success thực sau khi có labels; không dùng synthetic identity match thay relevance.
- [ ] Mở rộng finite grammar/domain/language có tests và labels; planner LLM hiện chỉ constrained template, chưa hỗ trợ tùy ý mọi complex query/qualifier.
- [ ] Tải Agent lớn/concurrency cao, provider failures dài hạn và stable tail latency chưa đo;16 requests/run là exploratory. Chưa có error/duration trace riêng mỗi planning attempt; planner_attempts và tổng planning_ms có trong raw.
- [ ] Target TTLast3s chưa đạt ổn định: lượt cuối chỉ 2/4 generated samples đạt, P90 4371.83ms.
- [ ] Import CLI chưa có update/delete/revision workflow, external knowledge connector hoặc tự crawl facts.
- [ ] Không durable checkpoint/long-term memory/tenant isolation/public hardening; không mở rộng thành autonomous actions.

Giới hạn trên được tách khỏi phần mềm đã kiểm thử, không tuyên bố fully verified real-world Agent. Các nhãn IMPLEMENTED/TESTED_WITH_MOCKS/VERIFIED_WITH_REAL_DATA/NOT_VERIFIED ở mục A là ranh giới nghiệm thu.
