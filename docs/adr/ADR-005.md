# ADR-005 — Fast Search độc lập Agentic Search

## Trạng thái

Chấp nhận · 2026-11-03 · P2 mặc định disabled cho đến phase riêng.

## Bối cảnh

Đa số queries không cần relation reasoning. LLM trên mọi request tạo thêm latency, failure và compute cost; multi-intent không tương đương multi-hop.

## Quyết định

Fast router deterministic, dùng encoder/retrieval/filters/rerank tùy chọn. Agent chỉ explicit endpoint, dùng core retrieval port và PostgreSQL tools. Giới hạn hops/calls/tokens/total deadline; direct fallback phải có consent và disclosure. RAG là optional post-retrieval service.

## Phương án đã cân nhắc

LLM router cho mọi query; agent mặc định; keyword heuristic tự chuyển sang agent; hai đường explicit và typed. Chọn hai đường, không tự tăng mức reasoning khi câu dài/nhiều điều kiện.

## Lý do

Bảo toàn P0 và đo độc lập cost của P2. Dependency từ intelligence tới retrieval một chiều; generator outage không làm core unready.

## Đánh đổi

Người dùng cần chọn advanced mode; heuristic decomposition chỉ phủ pattern đã công bố. Relational coverage giới hạn theo facts và agent deadline có thể làm unresolved.

## Hệ quả

Feature/capability flags và regression LLM-off bắt buộc. API agent synchronous JSON trước, không SSE v1. Tool output step trước là input step sau; parallel clauses không tính multi-hop. FR-014/020/021/022, NFR-009, [SYSTEM_ARCHITECTURE](../architecture/SYSTEM_ARCHITECTURE.md).
