# ADR-006 — PostgreSQL + Qdrant + MinIO

## Trạng thái

Chấp nhận kiến trúc lưu trữ · 2026-11-03 · Chưa triển khai migrations/services.

## Bối cảnh

Identity/metadata/jobs cần transaction; vectors cần retrieval; image bytes cần private object access. Không có transaction chung của ba kho.

## Quyết định

PG authoritative UUID/lifecycle/metadata/index registry; Qdrant rebuildable vector projection; MinIO private original/thumbnail/staging. Stable UUID, source SHA-256 và immutable embedding manifest liên kết các artifacts. Browser tải qua authenticated content proxy.

## Phương án đã cân nhắc

Lưu mọi bytes/vectors trong PG; filesystem local + FAISS; public object URLs; ba kho với idempotent recovery. Chọn phương án cuối theo baseline, không claim nó có cost/latency tối ưu chưa đo.

## Lý do

Phân biệt durability/identity và retrieval projection, dễ thay adapter/reindex, hạn chế bucket exposure. Byte-hash unique xử lý exact duplicates; không đồng nghĩa perceptual dedup.

## Đánh đổi

Cần receipts/state/retries/reconciliation. Query metadata recheck có chi phí DB; search không HEAD mọi object nên có cửa sổ drift external deletion. Proxy thêm bandwidth tải ảnh nhưng không làm public bucket; tải content đo riêng search.

## Hệ quả

Delete tombstone trước cleanup, fence/drain writers rồi xóa mọi index/object, retry idempotent. Reindex isolated + model preload + active pointer. Data rights/retention cần chốt trước nonfixture user data. FR-005/006/008, SEC-02/03/08; [DATABASE_DESIGN](../architecture/DATABASE_DESIGN.md).
